# Todo App

A simple and responsive Todo application built with **ReactJS, HTML, CSS, and JavaScript**.  
This project demonstrates core frontend development skills including state management, component-based architecture, and user interaction handling.

## 🚀 Features
- Add, edit, and delete tasks
- Mark tasks as completed
- Responsive design for desktop and mobile
- Clean and minimal UI

## 🛠️ Tech Stack
- ReactJS (Vite setup)
- HTML5
- CSS3
- JavaScript (ES6+)

## 📂 Project Structure
- `src/` → React components and styles
- `public/` → Static assets
- `package.json` → Dependencies and scripts
